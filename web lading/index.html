    Guía Android

    Android: versión final pendiente

    No hay un APK final firmado y probado. En descargas de prueba puedes consultar el prototipo experimental. No instales archivos de sitios que afirmen distribuir Shomer en nuestro nombre. Cuando haya una versión validada, aquí aparecerán los pasos para instalarla.

    ¿Qué permiso necesitará el prototipo?

    Android pide tu consentimiento para compartir la pantalla. La captura se puede detener desde la notificación; el prototipo actual descarta los cuadros y aún no aplica el filtro. Las pantallas protegidas pueden no ser capturables.

    ¿Puedo usar Shomer Web en mi teléfono?

    La descarga actual es una extensión para navegadores de computadora. No ofrecemos una instalación móvil de esa extensión.

    Guía iPhone y iPad

    iPhone y iPad: todavía no disponible

    Se prepara una extensión para Safari, separada de la app de bloqueo. No hay una invitación de TestFlight ni una app publicada en App Store. Cuando exista una distribución autorizada, encontrarás aquí el enlace oficial y los pasos correspondientes.

    ¿Qué podrá hacer la app?

    El proyecto usa los controles de Apple para solicitar autorización y bloquear las apps o dominios seleccionados. No modifica imágenes dentro de otras apps; el proyecto aún necesita firma y pruebas reales.

    ¿Debo instalar un archivo IPA desde una web?

    No ofrecemos ese tipo de descarga. La distribución prevista es a través de un canal autorizado de Apple.

    Privacidad y permisos

    Qué necesita Shomer

    En tu navegador

    El análisis de imágenes de Shomer Web se realiza en tu equipo. La extensión pide acceso a páginas web para poder aplicar el filtro; puedes desactivarla o quitarla desde la página de extensiones.

    Control en Android

    El prototipo pide permiso de captura mediante Android y muestra una notificación mientras captura. Los cuadros se descartan; el filtro aún no está listo.

    Control en Apple

    La app en preparación solicita autorización de Family Controls para gestionar bloqueos. Los permisos se controlan mediante el sistema.

    Preguntas frecuentes

    Antes de empezar

    ¿Shomer cubre todo el contenido?

    No. La detección puede omitir contenido o cubrir de más. Los videos protegidos y algunos formatos tienen limitaciones.

    ¿Qué computadoras son compatibles?

    El proyecto incluye una extensión para Chrome, Edge y Brave en computadora. No contamos todavía con una tabla de dispositivos y versiones comprobados.

    ¿Cómo detengo Shomer Web?

    Abre la página de extensiones de tu navegador y desactiva o elimina Shomer Web. También puedes revisar sus ajustes desde el botón de extensiones.

    ¿Por qué no hay descarga para mi teléfono?

    Las aplicaciones móviles aún necesitan compilación, firma y pruebas en dispositivos físicos. No hay un instalador móvil validado.
